# TNG PKT

[English](README.md) | [한국어](README.ko.md)

TNG PKT는 HF SSB 오디오를 통해 문자 교신을 하는 Windows용 아마추어무선 프로그램입니다. 잡음과 페이딩 조건에 따라 사용할 수 있는 모드를 제공하며, SSB 오디오 경로로 문자를 송수신합니다. **TNG44**, **TNG5**, **TNG1**의 세 가지 독립적인 통신 모드를 제공합니다.

**현재 공개 소스 후보 버전: 0.11.2 Beta / Build 1009**  
제작자: **6L5TNG**

## 주요 기능

- 선택한 오디오 입력·출력 장치를 통한 실시간 문자 송수신.
- 송수신에 공통으로 적용되는 모드 선택과 오디오 중심 주파수 조정.
- 호출부호 매크로, 송신 진행 표시, 수동 중지, TNG1 **다시 보내기(Resend)**.
- 실시간 워터폴·스펙트럼 표시, 패킷 타임라인, 모드별 분석 패널.
- 도킹 가능한 패널, 레이아웃 프리셋, 창 배치 저장.
- WAV 파일 복호와 TNG44 송신 WAV 내보내기.
- 수신 이력, 세션 로그, CSV 내보내기.
- 한국어·영어 인터페이스, 최초 실행 설정, CPU·오디오 진단.
- Hamlib 또는 직렬 제어선을 이용하는 선택적 무전기 주파수 제어와 PTT.

## 모드

각 모드는 속도와 강인성의 목표가 다릅니다. 교신하는 두 무선국은 같은 모드를 선택해야 합니다.

| 모드 | 설계상 역할 |
|---|---|
| **TNG44** | **Standard / faster** — 비교적 양호한 HF 채널에서 빠른 문자 교신 |
| **TNG5** | **Robust** — 약한 신호와 페이딩에 대비해 문자 전송률을 낮추고 오류 보호를 강화 |
| **TNG1** | **Robust+** — 어려운 채널에서 복원을 우선하는 저속 블록 기반 교신 |

모드 이름의 숫자는 현재 측정된 문자 전송률을 뜻하지 않습니다. 수신 결과는 채널, 무전기·오디오 설정, 수신 PC에 따라 달라집니다.

TNG44는 한글을 포함한 UTF-8 문자를 지원합니다. TNG5/TNG1은 대문자, 숫자, 공백, 줄바꿈, 일부 문장부호로 구성된 공통 57자 문자 집합을 지원합니다. 소문자는 대문자로, 탭은 공백으로 변환합니다. 지원하지 않는 문자가 있으면 송신 전에 경고하며, 사용자가 같은 내용을 다시 확인하면 해당 문자를 제외하고 송신합니다.

## 공개 통신

TNG PKT는 아마추어무선의 공개 교신을 전제로 합니다. 메시지 암호화나 비밀키 통신 기능을 제공하지 않습니다. 무선 전송 부호화 방식은 공개되어 있으며, 오류 정정과 화이트닝(whitening)은 비밀성을 제공하지 않습니다.

프로토콜 설계, 송수신 처리, 프레이밍(framing), 오류 정정, 문자 매핑, 무선 전송 부호화는 [프로토콜 설명서](docs/PROTOCOL.ko.md)를 참고하십시오.

## 설치 및 실행

배포 설정은 **Windows x64**를 대상으로 합니다. 패키지 형태의 프로그램은 CPU 추론을 사용하며, GPU나 별도의 Python 설치가 필요하지 않습니다.

바이너리 배포에 설치 프로그램이 제공되는 경우 해당 버전의 `TNG-PKT-Setup-0.11.2.exe`를 사용하십시오. 시작 메뉴 바로가기가 설치되며, 바탕 화면 바로가기는 선택 사항입니다. 소스 실행, 패키징, 이전 Build 1005 설치에서의 이전 방법은 [설치 및 Windows 빌드 안내](docs/INSTALL.md)를 참고하십시오.

Windows에서 **Python 3.13**으로 이 소스를 실행하려면 소스 루트에서 PowerShell을 열고 다음 명령을 실행하십시오.

```powershell
python -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -r requirements.txt
& .\.venv\Scripts\python.exe neuromod_app.py
```

최초 실행 시 언어를 선택하고 호출부호를 입력한 뒤, 무전기에 연결된 오디오 입력·출력을 선택하십시오. 필요한 경우 무전기 연결도 설정합니다. 초기 설정에는 CPU·오디오 진단 기능도 있습니다.

교신하는 두 무선국은 같은 모드와 서로 호환되는 오디오 중심 주파수를 선택해야 합니다. 기본 오디오 중심 주파수는 **1500 Hz**입니다. 문자를 보내기 전에 모드 선택과 중심 주파수 조정으로 운용 설정을 맞추십시오.

설정, 레이아웃, 실행 로그는 `%APPDATA%\TNG PKT`에 저장합니다. 업데이트는 수동으로 설치하며, 자동 업데이트 확인·설치 기능은 구현되어 있지 않습니다. 프로그램을 제거해도 사용자 데이터 폴더는 보존합니다.

## 무전기 제어와 Hamlib

오디오는 모뎀 신호를 전달합니다. 선택적 CAT 제어는 주파수·모드 제어와 PTT를 별도로 제공합니다. PTT에는 DTR/RTS를 사용할 수도 있고, 무전기의 VOX를 사용할 수도 있습니다.

Hamlib은 **포함되어 있지 않습니다**. 로컬 또는 기존 TCP Hamlib 연결을 사용하려면 `rigctld`/`rigctl`을 별도로 설치하십시오. 사용 가능한 기능은 무전기, 백엔드, 인터페이스에 따라 달라집니다. [무전기 설정 및 연결 안내](docs/INSTALL.md#licenses-and-radio-connection-security)를 참고하십시오.

## Beta 범위와 제한

- 실시간 수신은 선택한 모드와 오디오 중심 주파수 주변에서 동작합니다. 세 모드를 동시에 수신하거나 전체 통과대역을 탐색하지 않습니다.
- 모드를 바꾸면 수신 상태가 초기화되며, 송신 중에는 모드 선택이 잠깁니다.
- TNG5/TNG1은 지원 문자에 제한이 있습니다. 누락되거나 CRC 검증에 실패한 부분이 있으면 일부 문자만 복원될 수 있습니다.
- 현재 WAV 내보내기는 TNG44를 사용합니다. 이전 WAV 형식의 호환성은 제한적입니다. [프로토콜 구현 범위와 제한](docs/PROTOCOL.ko.md#구현-참조와-제한)을 참고하십시오.
- 패키지 실행 환경은 CPU PyTorch를 사용하며 GPU가 필요하지 않습니다.
- 이 Beta 소스는 RF 검증 완료, 모든 무전기와의 호환성, 약한 신호에서의 성능 보장, 다른 디지털 모드보다 우수함을 입증하지 않습니다.
